## 👋 About me

Hi, I'm **Yevhenii**, a developer based in Prague. I build things that people actually use: websites, Telegram bots, AI-powered tools and full game servers for **Aion**. I like projects that start as "it would be great if…" and end as something running in production.

- 🎮 Designing and programming **Aion game servers**: server logic, data, custom features
- 🌐 Building **websites** and landing pages
- 🤖 Writing **Telegram bots** that automate real work
- 🧠 Working as an **AI engineer**: LLM-powered assistants, automation and integrations
- 🛠️ Making **desktop tools** for gamers, such as [Pulse](https://github.com/yshu17/aion-pulse)
- 🌍 I speak **Ukrainian 🇺🇦 · English 🇬🇧 · Czech 🇨🇿**
